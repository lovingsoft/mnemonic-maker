## 1. 选型速查

| 用户给的内容 | 首选方法 | 备选方法 |
|---|---|---|
| 单个单词 / 外文术语 | 谐音 | 联想 |
| 数字、编号、电话号码 | 谐音 | 结构化分块 |
| 历史日期 / 年份 | 谐音 | 结构化 |
| 有序步骤 / 流程 / 公式 | 押韵 | 结构化 |
| 无序清单（3–10 项） | 联想故事 | 结构化首字 |
| 长列表（10+ 项） | 结构化首字/缩略词 | 联想分段 |
| 抽象概念 / 定义 | 联想 | 结构化 |
| 分类体系 / 多分支 | 结构化分块 | 联想 |

口诀质量铁律：准确 > 好记。任何为押韵/好笑牺牲准确性的写法都判不及格。

## 2. 押韵顺口溜

**打法**
- 把要点编成 2–4 句、偶数句押韵的中文短句，最好节奏整齐（七字句最稳）。
- 优先「意义分组 + 对仗」：同类放一句，前后句结构对称。
- 韵脚选响亮、易发的字（ang / ao / i / an 等）。
- 若原内容有固有顺序（步骤、流程），口诀必须保留顺序。

**适用**：流程、步骤、公式、有序清单、操作规范。

**范例 1 — 操作步骤（颜色光的三原色：红绿蓝）**
- 知识点：光的三原色是红（R）、绿（G）、蓝（B）。
- 口诀：红绿蓝，三原光；混一起，白晃晃。
- 记忆逻辑：红绿蓝对应 RGB；「白晃晃」点出三色光叠加成白光。

**范例 2 — 公式（勾股定理 a²+b²=c²）**
- 知识点：直角三角形两直角边平方和等于斜边平方。
- 口诀：直三角，两短方，加起来，等于长。
- 记忆逻辑：「两短」指两直角边，「长」指斜边；「方」即平方。

**范例 3 — 操作规范（灭火器使用）**
- 知识点：提、拔、握、压（提灭火器、拔保险销、握喷管、压把手）。
- 口诀：一提起，二拔销，三握管，四压牢。
- 记忆逻辑：四字动宾结构严格对应四步顺序。

## 3. 谐音梗

**打法**
- 取原词/原音的近似中文读音，拼成一个有画面的短语或短句。
- 画面要具体、可成像（动作、物体、场景），不要抽象。
- 对外文词：拆音节逐段谐音，再串成画面。
- 对数字：用数字方言读音（0=令/洞，1=幺，2=两/兔，6=溜/柳，9=酒）或常见谐音字。

**适用**：单词、外文术语、数字、人名、日期、化学元素符号。

**范例 1 — 英文单词（ambulance 救护车）**
- 知识点：ambulance = 救护车。
- 谐音：俺不能死 → ambulance。
- 记忆逻辑：读音近似「俺不能死」，急救场景画面强，对应「救护车」。

**范例 2 — 化学元素（钾 K / 钙 Ca / 钠 Na）**
- 知识点：K=钾，Ca=钙，Na=钠。
- 谐音：K 甲（铠甲），Ca 盖（盖子），Na 拿（拿走）。
- 记忆逻辑：取符号读音/近似音：K→「铠/甲」，Ca→「钙/盖」，Na→「钠/拿」。

**范例 3 — 数字串（π 前几位 3.14159）**
- 知识点：π ≈ 3.14159。
- 谐音：山顶一寺一壶酒（3.14159）。
- 记忆逻辑：数字方言谐音成画面短语，顺口易背。

**范例 4 — 历史年份（1492 哥伦布发现新大陆）**
- 知识点：1492 年哥伦布航行到达美洲。
- 谐音：医生（1）撕（4）旧（9）鹅（2）→ 想象医生撕了一只旧鹅去远航。
- 记忆逻辑：1→医，4→撕，9→旧，2→鹅，串成荒诞画面锚定年份。

## 4. 联想 / 故事法

**打法**
- 把要记的若干项，按顺序编进一个荒诞、夸张、有动作的小故事。
- 每项都必须「出场」并和原意挂钩，不能漏项。
- 越离谱、越有感官细节（颜色/气味/声音/动作）越好记。
- 可用「定桩法」：先固定几个熟悉的位置/数字桩，再把内容挂上去。

**适用**：无序清单、配对项、抽象概念、需要强画面的内容。

**范例 1 — 无序清单（太阳系八大行星顺序：水金地火木土天海）**
- 知识点：水星、金星、地球、火星、木星、土星、天王星、海王星。
- 故事：水（金）地（火）木（土）天（海）—— 想象「水汪汪的金鱼在地上着火，木头土里长出天王和海王」。
- 记忆逻辑：取每颗行星首字串联成画面短语，顺序即清单顺序。

**范例 2 — 配对项（左脑管语言、右脑管空间）**
- 知识点：左脑=语言逻辑，右脑=空间想象。
- 联想：左手拿话筒演讲（语言），右手比划大房子（空间）。
- 记忆逻辑：左右身体绑定功能，画面化锚定。

**范例 3 — 抽象概念（经济学机会成本）**
- 知识点：机会成本=为得到某物所放弃的最高价值备选。
- 联想：你选了苹果，就只能眼睁睁看香蕉被别人拿走——丢掉的那根香蕉就是机会成本。
- 记忆逻辑：用「二选一必失其一」的具体场景解释抽象定义。

## 5. 结构化拆解

**打法**
- **首字串联**：取每项首字连成一句话/词，这句话本身好记。
- **缩略词**：取每项首字母组成可读缩写（英文尤宜），或中文首字成语。
- **逻辑分块**：把长内容按维度拆成几个小组，每组再记。
- **定桩法**：数字桩/地点桩（身体、房间、路线）作为固定挂钩。

**适用**：长列表、分类体系、多分支概念、需要精确还原的内容。

**范例 1 — 首字串联（战国七雄：齐楚燕韩赵魏秦）**
- 知识点：齐、楚、燕、韩、赵、魏、秦。
- 拆解：七雄首字 →「齐楚燕韩赵魏秦」，谐音成「凄楚燕寒赵胃秦」（画面：凄凉楚国、寒冷燕赵、胃疼的秦）。
- 记忆逻辑：首字直接对应七国，串成易记短语。

**范例 2 — 缩略词（RGB / HTML）**
- 知识点：RGB=红绿蓝，HTML=超文本标记语言。
- 拆解：直接记缩写并展开每字母含义。
- 记忆逻辑：缩写即索引，展开即全意。

**范例 3 — 逻辑分块（四大发明：造纸、印刷、火药、指南针）**
- 知识点：造纸术、印刷术、火药、指南针。
- 拆解：分两类——「写」类（造纸、印刷）、「用」类（火药、指南针）。
- 记忆逻辑：按「记录信息 vs 改变世界」两维分块，降低记忆负荷。

**范例 4 — 定桩法（购物清单：牛奶、电池、纸巾、苹果）**
- 知识点：买四样东西。
- 拆解：用身体桩（头→脚）：头上浇牛奶、手装电池、脸贴纸巾、脚踩苹果。
- 记忆逻辑：固定桩位作挂钩，逐项挂上，回想时走一遍身体即可。

## 6. 按内容类型速查

| 内容类型 | 推荐方法 | 小贴士 |
|---|---|---|
| 英文单词 | 谐音 + 联想 | 拆音节谐音，配强画面 |
| 数字 / 编号 | 谐音 / 分块 | 4 位一组，方言谐音 |
| 历史日期 | 谐音 / 结构化 | 年份拆两段分别谐音 |
| 公式 | 押韵 / 结构化 | 保留变量顺序 |
| 有序流程 | 押韵 | 四字句严格对应步骤 |
| 无序清单 | 联想 / 首字串联 | 荒诞故事或首字成语 |
| 长列表 | 首字串联 / 定桩 | 分段 + 桩位 |
| 抽象概念 | 联想 | 用具体场景解释 |
| 分类体系 | 逻辑分块 | 先分维再记 |

## 7. 组合技

当单一方法不够时，叠加使用，效果更稳定：

- **谐音 + 联想**：先谐音出画面词，再把这些词编进故事（适合 5–8 项无序清单）。
- **结构化 + 押韵**：先分块/首字串联，再给每块编一句押韵小结（适合长内容+需要精度）。
- **定桩 + 谐音**：桩位挂谐音画面（适合超长无序清单，如购物/待办）。

**组合范例 — 记住「唐尧虞舜夏商周」朝代顺序**
- 结构化：首字串联「唐虞夏商周」。
- 押韵：补成「唐尧虞舜夏商周，春秋战国乱悠悠」。
- 记忆逻辑：首字保顺序，韵文助背诵，二者叠加既准又好记。
