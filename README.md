# mnemonic-maker
把任意知识点变成好记的口诀（记忆法），帮助用户高效背诵与长期记忆。当用户需要记忆、背诵、或记不住某些内容时使用：单条求助（如「我老记不住XX，帮我编个口诀」）、批量词条（给一批术语/公式/日期各配记忆法）、或整段材料提炼（给一段教材/笔记，提炼关键口诀清单）。支持四种口诀风格并智能选型：押韵顺口溜、谐音梗、联想/故事法、结构化拆解（首字串联/缩略词）。不限学科——单词、历史事件、化学元素、法律条文、技术概念、考试知识点等任意内容均可。

记忆口诀生成器（mnemonic-maker）
Overview
把任意难记的内容转化为易记、可复现的口诀。核心不是替用户死记，而是产出「记忆脚手架」——让用户看懂映射逻辑后，自己也能复现，从而实现长期记忆。
你会怎么被触发（触发词）
下面这些说法都会命中本技能，直接用口语提即可：
- 「记不住 XX，帮我编个口诀」「给 XX 想个记忆法」
- 「把这段教材/笔记提炼成口诀」「帮我把这些知识点各配一句口诀」
- 「给我编个顺口溜记住 XX」「用谐音记一下这个单词/术语」
- 「这些术语怎么记比较快」「帮我做套记忆法」「怎么才能记住这个列表」
输入形态识别（先判断是哪一种）
1. 单条问答式：用户给一个知识点 / 术语 / 数字 → 产出 1 条口诀。
2. 批量词条：用户给一组条目（词条 / 术语 / 公式 / 日期列表）→ 逐条产出，统一成表格。
3. 整段材料提炼：用户给一段文本（教材 / 笔记 / 讲义）→ 先抽取关键记忆点清单，再逐条配口诀。

生成流程
1. 识别输入形态：单条 / 批量 / 提炼。
2. 若是整段材料：先列「关键记忆点」清单（逐条编号、提取要点），再进入第 3 步。
3. 对每条内容：判断内容类型 → 选 1 种主方法（可加 1 种备选）→ 生成口诀。
4. 必写「记忆逻辑」：说明口诀与原内容的映射关系，让用户能自己复现。这一步不可省略——这是记忆可迁移的关键。
5. 按对应输出格式呈现。

质量红线（必须遵守）
- 准确性第一：口诀必须忠实反映原意，不得为押韵 / 好笑歪曲知识。发现冲突时优先准确。
- 谐音要贴近原音且画面具体，避免生硬谐音。
- 联想要荒诞但具体（越离谱越好记），且每个被记项都必须出现在故事里，不漏项。
- 结构化拆解要保证首字 / 缩略词能对应回原项，不丢项、不错位。
- 每条都附「记忆逻辑」，否则用户无法复现，口诀失去长期价值。
